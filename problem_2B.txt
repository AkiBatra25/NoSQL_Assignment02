How to Run TF-Score (Problem 2b) Locally

1. Clean previous build files (optional):
   rm -rf classes output_local tfscore.jar top100_df.tsv q2b_final_scores.tsv
   mkdir -p classes

2. Compile:
   export JAVAC_CP="$(hadoop classpath):$(pwd)/opennlp-tools-1.9.3.jar"
   javac -classpath "$JAVAC_CP" -d classes WholeFileInputFormat.java TFScoreStripes.java

3. Package into jar:
   jar -cvf tfscore.jar -C classes .

4. Prepare DF cache file (using top100.txt output from Q2A):
   cp top100.txt top100_df.tsv

5. Run MapReduce Job (Local Mode):
   export HADOOP_CLASSPATH="$(pwd)/opennlp-tools-1.9.3.jar"
   hadoop jar tfscore.jar TFScoreStripes Wikipedia-50-ARTICLES/ output_local top100_df.tsv

6. Export Final Result:
   cp output_local/part-r-00000 q2b_final_scores.tsv

7. Verify Output (Schema: ID<TAB>TERM<TAB>SCORE):
   head -n 15 q2b_final_scores.tsv

Notes:
- Ensure opennlp-tools-1.9.3.jar is present in the same directory.
