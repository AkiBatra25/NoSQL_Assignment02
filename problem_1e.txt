Problem 1e: Local Aggregations (In-Mapper vs. Combiner)

Commands to Execute:
We implemented custom local aggregations in two ways for both Pairs and Stripes architectures:
1. In-Mapper Combiner (Map-class level): Caches map results in a HashMap and flushes them to the Reducer via the `cleanup()` method.
2. Hadoop Combiner (Map-function level): Uses `job.setCombinerClass(...)`.

The `run_all.sh` script runs the following local aggregation combinations automatically:

# Pairs In-Mapper
hadoop jar cooccurrence.jar PairsCooccurrenceInMapper Wikipedia-EN-20120601_ARTICLES out_PairsCooccurrenceInMapper_d$d $d
# Pairs Map-Function Combiner
hadoop jar cooccurrence.jar PairsCooccurrenceCombiner Wikipedia-EN-20120601_ARTICLES out_PairsCooccurrenceCombiner_d$d $d

# Stripes In-Mapper
hadoop jar cooccurrence.jar StripesCooccurrenceInMapper Wikipedia-EN-20120601_ARTICLES out_StripesCooccurrenceInMapper_d$d $d
# Stripes Map-Function Combiner
hadoop jar cooccurrence.jar StripesCooccurrenceCombiner Wikipedia-EN-20120601_ARTICLES out_StripesCooccurrenceCombiner_d$d $d

Comparison Table - Execution Times (seconds):

| Algorithm Variation         | d=1 | d=2 | d=3 | d=4 |
|-----------------------------|-----|-----|-----|-----|
| Pairs Average (Baseline)    | 269 | 284 | 168 | 160 |
| Pairs with Map Combiner     | 270 | 300 | 165 | 169 |
| Pairs with In-Mapper        | 286 | 740 | 161 | 161 |
|-----------------------------|-----|-----|-----|-----|
| Stripes Average (Baseline)  | 268 | 177 | 162 | 164 |
| Stripes with Map Combiner   | 287 | 171 | 160 | 165 |
| Stripes with In-Mapper      | 290 | 168 | 159 | 162 |

Observations:
The Stripes approach generally outperforms the Pairs approach due to emitting fewer, but larger, key-value pairs (using MapWritable), significantly reducing network I/O during the shuffle phase. Combiners successfully lower data transmission off the Map nodes but can slightly increase execution times in edge cases (e.g. Pairs In-Mapper for d=2) due to Java Garbage Collection overhead and internal dictionary memory limits when combining highly diverse distinct values in large context windows.
