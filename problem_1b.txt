Problem 1b: Pairs Approach

Command to Execute:
To run the Pairs approach program for distances d=1, 2, 3, and 4, we use an automated execution bash script `run_all.sh` that compiles the java classes, creates the jar, and runs the following command for each distance `$d`:

hadoop jar cooccurrence.jar PairsCooccurrence Wikipedia-EN-20120601_ARTICLES out_PairsCooccurrence_d$d $d

Execution Times:
The execution time (in seconds) for each context window distance parameter (d) using Hadoop in Standalone mode on WSL:

w = 1 (d=1): 269 seconds
w = 2 (d=2): 284 seconds
w = 3 (d=3): 168 seconds
w = 4 (d=4): 160 seconds
