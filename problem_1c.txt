Problem 1c: Stripes Approach

Command to Execute:
To run the Stripes approach program for distances d=1, 2, 3, and 4, we use the `run_all.sh` script to automate execution. For each distance `$d`, the following core command is run:

hadoop jar cooccurrence.jar StripesCooccurrence Wikipedia-EN-20120601_ARTICLES out_StripesCooccurrence_d$d $d

Execution Times:
The execution time (in seconds) for each context window distance parameter (d) using Hadoop in Standalone mode on WSL:

w = 1 (d=1): 268 seconds
w = 2 (d=2): 177 seconds
w = 3 (d=3): 162 seconds
w = 4 (d=4): 164 seconds
